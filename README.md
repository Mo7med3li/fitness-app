## ✨ Features

- 🌍 **Multilingual UI** — Full AR/EN language support via React-Intl
- 🔐 **Secure Authentication** — Protected routes and session management
- 📋 **Advanced Form Handling** — Type-safe forms with validation
- 📡 **Efficient Data Sync** — TanStack Query for server state management
- 📱 **Fully Responsive** — Optimized for mobile, tablet, and desktop
- 🤝 **Agile Built** — Developed collaboratively using Scrum methodology

## 🚀 Getting Started

### Prerequisites

- Node.js 18+
- npm or yarn

### Installation

```bash
# Clone the repository
git clone https://github.com/Mo7med3li/fitness-app.git

# Navigate to the project directory
cd fitness-app

# Install dependencies
npm install

# Start the development server
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.

## 🌍 Internationalization

The app supports **Arabic** and **English** using React-Intl. Language can be toggled at runtime. All UI text, form labels, and validation messages are fully translated.
